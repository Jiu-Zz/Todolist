# Todolist

## 项目简介

这是一个使用原生 HTML、CSS 和 JavaScript 编写的简易待办事项页面。当前项目以单文件形式实现，适合作为前端基础练习示例。

## 文件结构

- `todolist.html`：项目核心页面，包含页面结构、样式和交互逻辑
- `.git/`：Git 版本管理目录

## 当前功能

- 在输入框中输入内容后，按回车可添加新的待办事项
- 每条待办事项都可以切换为完成或取消完成状态
- 每条待办事项都可以被删除
- 每条待办事项都可以编辑并保存修改
- 支持按 `全部 / 未完成 / 已完成` 筛选待办
- 支持一键清除已完成事项
- 已完成事项会显示删除线，并使用灰色文字区分状态

## 实现方式

- 技术栈：原生 HTML + CSS + JavaScript + `localStorage`
- 页面使用一个内存数组 `list` 保存待办数据，并通过唯一 `id` 管理每条任务
- 每次数据变化后，通过统一渲染流程刷新页面
- 当前数据会同步保存到浏览器本地存储，刷新页面后仍然保留

## 已知问题 / 当前限制

- 当前没有后端存储或账号系统，数据只保存在本机浏览器中
- 当前没有拖拽排序、快捷键大全等进阶交互
- 当前没有把界面拆分成多文件，仍然是单页实现

## 可继续改进的方向

- 增加待办数量统计和已完成数量统计
- 增加拖拽排序
- 增加快捷键操作
- 进一步优化页面布局和视觉样式
- 拆分成更清晰的多文件结构
