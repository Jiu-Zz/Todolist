# Todolist

## 项目简介

这是一个使用原生 HTML、CSS 和 JavaScript 编写的简易待办事项页面。当前项目以单文件形式实现，适合作为前端基础练习示例。

## 文件结构

- `todolist.html`：项目核心页面，包含页面结构、样式和交互逻辑
- `.git/`：Git 版本管理目录

## 当前功能

- 在输入框中输入内容后，按回车可添加新的待办事项
- 每条待办事项都可以切换为完成或取消完成状态
- 每条待办事项都可以被删除
- 已完成事项会显示删除线，并使用灰色文字区分状态

## 实现方式

- 技术栈：原生 HTML + CSS + JavaScript
- 页面使用一个内存数组 `list` 保存待办数据
- 每次数据变化后，通过 `renderTodoList(list)` 重新渲染列表
- 当前数据仅保存在页面运行时内存中，刷新页面后不会保留

## 已知问题 / 当前限制

- `todolist.html` 中虽然写了示例待办项（如“吃饭”“锻炼”“写作业”），但脚本启动时会将 `list` 初始化为空数组，并立即重新渲染列表，因此这些示例项默认不会显示
- 当前没有使用 `localStorage` 或后端存储，数据无法持久化
- 当前没有提供筛选、计数、分类等更完整的待办管理能力

## 可继续改进的方向

- 增加 `localStorage` 支持，保留刷新前的数据
- 增加待办数量统计和已完成数量统计
- 增加“全部 / 未完成 / 已完成”筛选功能
- 优化页面布局和视觉样式
- 增加初始示例数据的正确加载方式
